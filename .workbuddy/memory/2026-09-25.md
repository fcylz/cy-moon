## v1.15.2 · 字卡/表情重复 + 云端表情拉不到

**重复问题确实是云同步造成的**，两个独立来源：

1. 云端导入 id = `"c"/"sk" + Date.now()`，两台设备各导入同一批 → id 不同 → `_mergeById` 当成两条，
   同步一轮多一份。
2. 表情 src 域名换过（raw → jsdelivr），同一张图两个地址，src 判重失效。

修复：新增 `_cardKey`(cat+正文) / `_stickerKey`(取 `/Meme/` 后路径，抹掉域名) /
`_dedupeBy(list,keyFn,better)`；
`_mergeCards`/`_mergeStickers` 取代 cards/stickers 的 `_mergeById`；表情同图优先留非 raw
（raw 本机不可达，`_stickerRank`）。三处导入（云端字卡/云端表情/粘贴链接）统一判重键。
新增 `window.dedupeLib(auto)` 清历史重复，启动 1.5s 后自动跑一次（幂等，没清掉不写盘）。

**云端表情拉不到**：云端索引缓存**无 TTL** 且 `refreshCloudCards/refreshCloudStickers`
在 index.html **没有任何调用点**（只有音乐库有刷新按钮）→ 云端新增永远进不来。
修：`CLOUD_INDEX_TTL=6h` + fetch URL 追加 `t=Date.now()` 绕过 CDN 缓存 + 两个云端库弹窗加
「刷新云端」按钮（刷新后就地重渲染）+ 弹窗补状态行
（原来 `updateCloudStickerStatus` 找不到元素，状态从不显示）。

抽片段跑 10 项断言全过（跨设备去重/保留本机/域名归一/不误删/幂等）。

⭕ 经验：`_mergeByKey` 只按 id 的合并策略，对「内容来自外部导入、id 是时间戳生成」的数据源一律不够，
必须再叠一层内容键去重。
